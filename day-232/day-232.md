#  Tidy Up Migration
Welcome to **day 232** of 365 days of code - coding every day for a year, little and often

I was taking a look through the codebase today, thinking about what I would do next when I realised, I never removed all of the user migrations piece from when I forced user set up to be a thing. So today it was time to tidy all of that up.

Yes it means if anyone is actually running this, and they haven't updated their instance since v0.6.3, then it's all going to turn upside down for them, but the chances of that are...slim, so it's time to clean up.

I started off by removing all of the logic for this from the instrumentation file, then removed all the proxy settings that I had for this. I then deleted out the components for the usermigration page, removed the column I had in the users table for migrations, generated the migration, and away we go!

And then I went to merge the PR, and realised I hadn't updated the tests and that made the build fail. Unfortunately I was out of time for the day, so as always, tests get their own day tomorrow.
