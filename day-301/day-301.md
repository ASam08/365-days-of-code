#  Detail Card
Welcome to **day 301** of 365 days of code - coding every day for a year, little and often

A bit of a change of direction today, I was going to look at the rate limit stuff but just needed to flex some different muscles, so I took a look at the detial card.

This may eventually end up being the edit item card, but for now it's a way of popping up the full image, and any other details that might be hidden in the home/wardrobe screen. It also allowed me to move the delete away from the main screen.

For now it just has the same details as the main screen, but will the full size image, but it opens the door for some more work coming up, so all good progress. More tomorrow!
