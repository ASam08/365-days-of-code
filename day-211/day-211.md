#  Hello Base UI
Welcome to **day 211** of 365 days of code - coding every day for a year, little and often

I mentioned a few days ago that I was thinking about moving from RadixUI to BaseUI, and today I kicked that process off. I guess there is a big question, why? Radix UI is still well supported by shadcn and they have publicly said that they intend to carry on supporting it, with one caveat "unless a component only exists in Base UI". 

Now, I realise that the likelihood of me coming into a situation where I really feel like I need or want to use a component that only exists in Base UI is slim, however, it's possible, and I feel like if I'm going to migrate, it's never going to be easier than it is today. By that I mean, the more code I write and components I add, the more I have to change later on down the track, so it's harder than it was yesterday, easier than it is tomorrow.

The other big reason for why, because I can. Remember this whole thing is about learning code, experiencing different situations, a migration like this is a good learning opportunity for me, so maybe the question should really be why not?

At the end of the day, it's my decision and I'm doing it.

Anyway, on to what I actually did today, before I started any of this, I did merge a quick dependabot update, and pushed that into a new release as it did have some package vulnerability remediations in it.

I then came up with a plan on how to attack the Base UI migration, read a bunch of docs, and kicked it off with migrating the label component. Now the great thing about the label component, no change to the way it's used, so no real code change, just installing the updated component.

And that's when I ran out of time for the day, so I guess check in for more tomorrow!
