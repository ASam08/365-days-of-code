#  One Form, Two Uses
Welcome to **day 304** of 365 days of code - coding every day for a year, little and often

Today I moved on to working on the edit item form, and a thought hit me, this is going to be almost a replica of the create item form, why can't I share the form. So I have started adjusting the create form to be an item form. The idea is that the same form can be called with a calledType prop which changes the behaviour from create to edit.

I've started putting this in, it's going to take a little work to get the image piece right, as I am limiting users to just one image at the moment. And also some work to test out the whole thing. I've also ended up in a bit of a type catch 22 that I need to resolve tomorrow, but there is good progress and I'm reusing existing code so that's always a good thing.
