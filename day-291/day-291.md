#  Image Schema
Welcome to **day 291** of 365 days of code - coding every day for a year, little and often

Today was a bit more of a comfortable day for me today, sorting out the image table in the DB. This was pretty straight forward, going with my plan I had for this, add the schema, and the relations, generate the migration, check it all works, and happy days!

The relations are good for cascading deletions when users/items are deleted, but I will need to make sure to handle getting rid of the images out of s3/Garage as well as just deleting them from the DB helps no-one. I possibly should create a script that runs on a cron schedule as well that deletes any images more than 24 hours old that don't have a reference in the DB, that way I won't end up with any orphan images if something fails to delete the image upon user/item deletion.

Anyway, tomorrow will be creating the server actions for uploading images, then we should be able to put some UI around it and actually take this thing for a test drive in the next couple of days, exciting!
