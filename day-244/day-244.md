#  Protected Colour
Welcome to **day 244** of 365 days of code - coding every day for a year, little and often

Today I went through and added in some protections against the race condition I mentioned yesterday, specifically I moved the value change piece into a useEffect, so that it cleans up the old fetch when it starts a new one, nice and neat and tidy. I also at the same time added in debouncing for the subject field, to reduce server calls, I didn't want to make 7 calls everytime someone typed "Biology", so a 300ms debounce seems to work nicely.

And actually I think that's it, I'm really happy with this piece, I could look at adding in something to the edit block form, but that will be something for another day I think, the plan is to release this as it is for now and then go from there.

I of course have to write the tests for this, so that will definitely be a tomorrow job!
