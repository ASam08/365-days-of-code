#  What Was That Colour?
Welcome to **day 242** of 365 days of code - coding every day for a year, little and often

Next up in the colour series, suggest a colour based on the subject chosen. So I have been thinking about the best way to implement standard colours across a subject, and to be honest it's a bit painful. How do I know if a user is intentionally trying to change the default colour for a subject, or making a mistake, or trying to change just that one, without a whole bunch of prompts. I've decided to go with a simpler method: when a user is adding a block, change the colour to the colour of the last created block of that subject on the set. It seems to be the least frustrating way, and fits in with how most users will use it (I hope). I haven't decided what to do about editing blocks, but luckily that will be a decision for another day.

Today I didn't have much time, so I just wrote out the data function to grab the colour of the last created block in a set, with a specific subject. Nothing too fancy or complicated, but it's all I had time for. That means I haven't implemented it anywhere, so no testing of the function as of yet, but I guess that's what tomorrow is for!
