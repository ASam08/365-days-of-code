#  Goodbye Radix UI
Welcome to **day 212** of 365 days of code - coding every day for a year, little and often

Another mini-project, another checklist...yay? I rattled through a few more of the radix -> base migrations today, the first few were straight forward, no changes needed, and then I did Button...

Button had some changed needed becaue asChild is not a thing in base ui, the idea is to convert this to use render instead, which actually works pretty nicely. Luckily I had used pretty much the same thing a bunch of times, so I just had to find them all and replace them, with pretty much the same code too. They were all the cancel buttons on my forms. I actually discovered I had some set up as nested, but without the asChild, from before I knew better I guess. The issue with that is there are then technically two live elements, both clickale, screen readable, tabable (word?). Anyway, that problem is no more, and Button is done. 

Except that Button is used in a bunch of other components, which is why it had to happen early on, but it means that there is now broken code in the branch, in this case until AlertDialog is done.

Anyway, good progress today, and the first thing that wasn't just straightforward, more tomrorow!
