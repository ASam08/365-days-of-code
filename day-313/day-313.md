#  Grid Filter
Welcome to **day 313** of 365 days of code - coding every day for a year, little and often

A good progress day today, getting the grid actually filtered (finally!).

It took a fair bit of work, one of the decisions I've made is to just filter on the client side. I know it means retrieving all items at the start, but to do it server side would just end up resulting in a lot more requests, and the initial page load is already going to load them all anyway, because it won't start filtered.

I've also used URL params for the filters, it just keeps things nice and easy, and isn't a bother for users generally.

Just one thing I want to look at on this (a tomorrow job) is to have a clear filters button next to the filters button, but only when there are active filters.
