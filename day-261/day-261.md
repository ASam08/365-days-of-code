#  Ground Work
Welcome to **day 261** of 365 days of code - coding every day for a year, little and often

A pretty short day today, not a lot of time, but I did go through and plan out the db schema for the wardrobe items. One thing I had to think about is how to handle my user choices, in particular the item categories. Colours was easy, that will be hex, and seasons I ended up putting into a pgenum to get the DB to have the defense for it, especially seeing as how the 4 seasons will (probably) never change.

For categories, I'm going to go with a set of defaults that every user will get, but other users can add their own categories as well. All of the categories will be stored in a DB, with an ownerID of null if it is a default one, and then an index on the categories table to guard against a user creating a custom category twice, or one that is the same as a default one. I'll then seed the DB with the default categories via a migration before this goes out as v0.1 (once I've thought about what they should be).

It's an approach I haven't taken before, because I haven't needed to, but I've done the research and I'm comfortable (enough) with what I'm doing, plus, this is all about learning at the end of the day.

Tomorrow will be more work on the backend so that I can then start on the UI piece. More then!
