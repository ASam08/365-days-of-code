#  Let There Be Colour
Welcome to **day 222** of 365 days of code - coding every day for a year, little and often

A pretty big day all around today. Starting off with the development work.

I managed to put together:
- Adding the field to the blocks db table
- Adding colour to the retrievedtimetableblocks type
- Updating every action or data function that uses blocks
- Updating the timetable page to actually show the new colours
- Adding the colour picker to the edit block page
- Creating constants into the constants file and a default colour in the defaults file, to keep things consistent and one place to update

Not bad for about 90 minutes work. It all came together pretty quickly in the end, once I worked out my plan, I just kept ticking things off quicker than I thought, so I had time for the next thing and before I knew it, I'd done everything listed above. And it actually worked!

A few gotchas, the biggest one was forgetting to "import type" instead of "import" for importing the timetablecolour definition and the constant, seeing as how having them in the lib/definitions and lib/constants files, along with the other colour constants in the lib/constants file, means that the two files feed off each other, that was important to have done up front.

So now we have at least an MVP, we can choose colours per block, edit them and show them. I'm considering releasing just that functionality for now and tackling the other part, default colours per subjects etc. as a separate feature. Either way I don't have to decide today, because of course I haven't updated or created any tests at all yet, so guess what I'm doing tomorrow...

I also took some time to do some much needed package updates, dependabot had a bunch for me to do, but also I had a few vulnerabilities in there, mostly from dev dependancies, that needed me to go off and do it for myself. So I switched back to main, did all of those, merged them into main, then merged main into the colour feature branch so that I had those package updates too.

Anyway, enough for one day, more tomorrow!
