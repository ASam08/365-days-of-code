#  Mobile Testing
Welcome to **day 295** of 365 days of code - coding every day for a year, little and often

Ok, today was a wrap up from yesterday day. I got into testing the image resize functions, first on desktop, which was all fine, and then on mobile. For mobile, I had a little work to do to enable access from another device locally, setting up the allowed dev origins for nextjs and the allowed origins for better-auth. I ended up putting these both in as environment variables, so I don't accidentally commit IP details in the config files.

From there, I tested the mobile upload/resize through, all worked well, but I wanted to add in some better failure handling for wrong filetypes, so added that in and called it a day. Tomorrow will be wiring the image uploads into the create item form, we're getting there!
