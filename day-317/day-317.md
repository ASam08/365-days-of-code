#  React Hook Account Form
Welcome to **day 317** of 365 days of code - coding every day for a year, little and often

Ok, so after yesterday, I decided I did want to go down the route of making the account form a react hook form(s). The challenge to doing this was I did have to split it out and properly create 3 different forms. It meant getting rid of some of the shared logic that they had, and creating more components, but then I realised I could actually just put some of the shared logic into a component of it's own and call it from the forms.

So I went from the account form component, with all the schema housed inside it to:
- Account form is just a shell that houses the tabs, each tab renders one of the three forms
- Three form components, one for each form type. On submit they call the run-auth-action component, which handles the toast notifications
- the run-auth-action component, which handles the toast notifications, to be fair this name probably needs to change, as it's not great at saying what it does, but that's what I had already called it...

And it's done, and working! I probably should change that name of the shared component, I can add it into the jobs list for tomorrow, when I hopefully start the admin page piece...
