#  Choose Your Subject
Welcome to **day 225** of 365 days of code - coding every day for a year, little and often

Well another day and I've picked up another little UI/UX thing that I would like to do. It sort of feeds into the next bit that I want to do on the colour front as well. I want to make the subject field in the add and edit timetable block forms an autocomplete, so that when you start typing, you get a list of subjects that you've already entered, but you can still type a new one if its...new...

Anyway, I thought the best way to do this was a combobox, I read some docs and went about implementing it. I created the data function to get the current subjects on a given timetable, passed that into the client component on the addtimetableblock page, and started putting the combobox together.

Well, after getting through it a bit, I realised I hadn't read *all* the documents... It turns out with Base UI, I do actually need to use an autocomplete, the combobox option won't take a new value into it. So a little bit of work potentially down the toilet, but all a good learning experience.

I haven't quite worked out where to take it next, I have a few ideas, but will see how they turn out tomorrow.
