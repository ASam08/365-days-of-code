#  Type Type
Welcome to **day 305** of 365 days of code - coding every day for a year, little and often

And just like that, we're into the penultimate month of this project, and of this year, that feels pretty crazy to say to be honest...

Anyway, today was spent fixing the typing issue I had yesterday, it turns out I had all the right elements there, but drizzle just needed me to re-order things in the schema. I had ``colours: text("colours").$type<ColourName>().array() `` instead of ``colours: text("colours").array().$type<ColourName[]>(),`` and for whatever reason, Drizzle couldn't handle that, so I switched it up and that fixed my type issue. I then did a little work on the rest of the current create-item-dialog component, getting the onSubmit ready, hiding the image upload in the edit side (that will have to be sorted out later), and setting the types for the props to be a union for the calledType and existingItem, so that in the edit case, one can't exist without the other. I'm sure that is going to save me one day in the future.

I did have to put in a dummy updateItem function, at the moment it just checks the userID and then makes sure that the user owns the item they are trying to edit, to prevent a crafted request being allowed to update someone elses item.

Tomorrow should be sorting the rest of that function out, and maybe getting the function actually used somewhere, let's see...
