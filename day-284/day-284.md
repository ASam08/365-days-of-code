#  Spell It Right
Welcome to **day 284** of 365 days of code - coding every day for a year, little and often

At the start of this project I screwed up. I let an autocorrect hit me in VSCode, and today I finally went back and sorted it. In most countries in the world, colour is spelt with a u, including where I'm from, so today I generate a migration to fix this. I was generating a migration anyway as I was changing the type in the DB of colour to have to be one of the constants for colour anyway, so changing the spelling seemed timely.

On that, yes I sorted out the validation for colour in the DB as well, both in zod for the form, and in the DB itself, so now colour has to be one of the ones from the list. I should probably add in a blank or unknown, or other field as not all items will be one of these colours, but that's a job for another day. I'm also thinking I should let items be more than one colour... Something to think about, maybe for tomorrow...
