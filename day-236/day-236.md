#  Time Bar Tests
Welcome to **day 236** of 365 days of code - coding every day for a year, little and often

A pretty straight forward day today, writing up the tests for the timetablegrid component changes to add in the time bar. They all went in well, and all passing (hooray).

While I was looking through the code to add the tests, I spotted that I was getting the current time, then running my processing, then setting the scheduler with that same first time, which was a little bit stale (only a few ms but still...). So I tweaked the useEffect a little to account for that, now I get one for rendering the timebar, then one for the scheduler to set the next change. Small things, but good to get them right and efficient.

Anyway, with that, the PR is merged, and the release is out (along with some package updates). Let's see what comes tomorrow!
