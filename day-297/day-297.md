#  Card Thumbs
Welcome to **day 297** of 365 days of code - coding every day for a year, little and often

It really is all starting to come together! Today was adding in the thumbnails to the clothing card, and all of a sudden the home page actually shows you your clothes, a big step forwards! Adding the thumbnails in was relatively straightforward, since I had already set up the infrastructure underneath it all. One thing I did spot is that I was trusting userID's passed into some of my data functions, so I got rid of those and replaced it with the better-auth api call in the functions themselves, to be sure I was getting it correct, and remove any injection opportunities etc.

Anyway, I now need to add in the ability to delete items, delete or replace images, and then I guess edit items too. That will all come up in the next couple of days, then move onto adding the filters. It's getting there!
