#  Can You Fix It?
Welcome to **day 231** of 365 days of code - coding every day for a year, little and often

Well as it turns out I didn't have to think to hard about what to do today. My own personal instance of Tempus updated to the new docker image overnight, and when I looked at my phone this morning, I had numerous alerts about a hung container.

The good news, it had nothing to do with the autocomplete work. The bad news, I didn't know what it was. After a whole bunch of digging it turns out that it was NextJs' standalone output file tracing failing to correctly resolve pnpm's symlinked, hashed store paths. At least that's what the internet told me. It seems it's a fairly common pain point when using NextJs in standalone mode, but also a pretty quick one to solve:
1. Add a .npmrc file with "node-linker=hoisted" in it
2. Add that to the copied files in the dockerfile

That's it.

The hoisted node-linker tells pnpm to lay out node_modules flat instead of nested symlinks, then nothing gets lots and everyone is happy (apparently).

Anyway, that worked, I merged that branch in, tested the docker container in dev first (this time), added another release, and all is well in the world again. We learn something new everyday, I wonder what will happen tomorrow...
