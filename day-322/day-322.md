#  Admin Harden
Welcome to **day 322** of 365 days of code - coding every day for a year, little and often

Today was a bit of a different day, but probably a day I should run more often. I gave all of the admin components to Claude today as a pair programmer and asked for a full review, any issues that I had missed or made. It found a handful of things to look at.

Full disclosure - yes it gave me replacement or changes to the code. No I did not just add it all blindly!

I went through each recommendation one by one, reviewed the rationale, found (in most cases) the errors of my ways, and tidied things up. While I was doing that, I expanded the use of the toast notifications, so now on the admin page, toast notifications come up confirming every change, which is nice.

There were a few other places where a user could have ended up with a weird looking page, so I got them sorted out too, and voila, admin is done!

Hopefully I should be able to rattle through setting up jest tests (boring) over the next few days, and then I can get into dockerising this baby and releasing it!. I do need to come up with a good name though...
