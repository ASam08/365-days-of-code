#  Sweep It Up
Welcome to **day 299** of 365 days of code - coding every day for a year, little and often

Today was a good day, implementing the orphan image sweeper function. This took a fair bit of thinking about the right way to do it, and I settled on the following:
- Check the db, if it's empty, don't run the function (something's wrong)
- Check for any images with image keys not in the db
- Check if they are more than an hour old (url's have a 5 minutes life so there is some decent margin here), if they are younger, ignore them
- Delete the images from S3 that fulfil the criteria (not in db and more than an hour old)
- Use the logs for reporting back the results, a line per image deleted and a summary
- Runs on startup via instrumentation, which starts a timer
- After 1 hour, if the function is still running, it kills it
- After 24 hours, the job runs again (for regular maintenance)
- Most of the above is changeable via env variables

I'm pretty pleased with how it's all come together, I think I've thought of most things, and it does appear to work, I had orphan images that I knew were in my DB, and on the first run it got rid of them. I added in a dry-run capability too, but didn't think to use that on the first run. I do need to do some more testing on it, but it seems pretty solid so far, so a good day.

Not 100% sure what I'll be doing tomorrow, hopefully testing this through more, but maybe looking at rate limiting requests as well, particularly for uploads, we'll see.
