#  Create Category
Welcome to **day 286** of 365 days of code - coding every day for a year, little and often

Picking up on the plan from yesterday, I went ahead and implemented the create category functionality into the create item flow today. Because of all the state control in the category field for this, and the fact that I'll have to implement it for editing an item, I went with turning the category field into it's own component. I'm really pleased with how this came together, it looks good and works well. I had to make some changes to the create category field to allow it to be called from create item as well as a few schema changes, but nothing too drastic. One thing I did need to take care of was the potential for a race condition in the create category field.

Next up tomorrow will either be storing images or custom tags, I guess I'll work that out tomorrow.
