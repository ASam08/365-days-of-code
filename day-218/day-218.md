#  Cheers To Deletion
Welcome to **day 218** of 365 days of code - coding every day for a year, little and often

I was trying to work out what today's goal was going to be, when I remembered, I had left myself a TODO in the last few days.

When I was working through testing everything for the base ui move, I spotted that in the manage timetable sets page, I could have an error when deleting a timetable set, but no way to give feedback to the user that something was wrong. It was a pretty simple fix, add in toast notifications for success and failure. The only issue was that I was redirecting to the timetable page from the action, so a quick fix later, now the component pushes to the timetable page on success, and displays a toast notification either way, success or fail.
