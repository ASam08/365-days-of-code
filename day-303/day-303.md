#  File Button
Welcome to **day 303** of 365 days of code - coding every day for a year, little and often

Another day of little bits. First up I wanted to make the choose file button for image uploads actually look like a button, luckily this is configurable, although not in the shadcn documentation, so it was good to sort that out.

Next up, I wanted to tweak the big opened item cards. For starters it needed a max height full so that it didn't open taller than the screen. Then I realised that if I used the delete button, it wouldn't get rid of the selected item and cause a bit of an issue, so I sorted that out.

Lastly I wanted to remove the margin between the card and dialog for the create item dialog and the opened card dialog.

All in all I'm much happier now with how things are looking, I can start looking at the next thing now I think. More tomorrow!
