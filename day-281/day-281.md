#  It's A Grid
Welcome to **day 281** of 365 days of code - coding every day for a year, little and often

Another good day today, starting off by changing the items grid to actually be a grid. I then had need to add some more test items to my dev instance and realised that the form was not closing or refreshing the page upon submit. After a little looking, I realised the easiest way to do this was to roll the dialog into the create item form component, making is a create item dialog component, that way I could control the dialog from the same component and not try and push state backwards and forwards, especially because the dialog was originally on the page component, so server based vs client based for the actual form.

Anyway, all of that is done now, not sure what I'll tackle tomorrow, maybe the colours drop down...
