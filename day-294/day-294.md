#  Image Resize
Welcome to **day 294** of 365 days of code - coding every day for a year, little and often

A bit of a half complete one today. I set to work on the image resize piece for the uploads. Effectively what it is, is a client side functionality, that takes the full size image from the user, and creates a full size image, and a thumbnail version. In the wardrobe main page, the thumbnail is what will be seen, but in the edit page or the outfit page, it will use the full size image, and I don't want to be scaling these on the fly each time, so have two images, with the conversion happening client side at upload time seemed like the way to go.

I've written out the functions, and done a little testing, but I do need to test a bit more on how this works with iPhone image uploads, as that ecosystem can be a bit tricky, hopefully I get a chance to test drive that properly tomorrow. The commit is in nonetheless, but potential fixes on their way tomorrow.
