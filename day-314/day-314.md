#  Clear Filters
Welcome to **day 314** of 365 days of code - coding every day for a year, little and often

Another good day today, sorting out my clear filters button. I went with adding it in as part of the filter dialog component, the two buttons go hand in hand with each other, so it made sense to have them in the same place. I didn't however want to write out everything to work out if I had filters or not, like I have already had to do with the wardrobe grid, so I moved the inline function from the wardrobe grid into a hook, added in the function to clear the filters, and used that instead. It felt good to actually reuse code in this way, remembering that if I'm using it more than once, it's worth just putting into it's own component, or in this case because it's a client function, a hook.

Anyway, it let me do some nice things, like only show the clear button when there is a filter, change the colour of the filters button to show when there are active filters, all that good stuff.

I think we're good here on the filters piece for now. I think from here I'll probably look at setting up the account page (change email address, change password etc.), which is probably going to mean wiring in emails with resend. Then add in the admin page to manage users and I think we'll be pretty close to a v0.1 release... I feel like I've said that before...
