#  Categories Seeding
Welcome to **day 262** of 365 days of code - coding every day for a year, little and often

Another relatively short day, but some meaningful progress today. I seeded the default categories list today, my first time using the generate custom migration option in Drizzle, and actually it was super straightforward (as everything with Drizzle appears to be so far). I added the migration, booted up the dev app, and realised I had no way to see if it had worked properly.

I did jump into Drizzle studio quickly to sanity check, and of course they were all happily sitting in the table, so I knew I was in good shape, but I wanted to see them in the app (of course). So I added a function I am going to need soon anyway, retrieveCategories, which pretty much does what it says on the tin and retrieves all of the categories for that user AND the default ones. I just output it straight to the home page for now to check everything worked, that won't stay of course.

Anyway, a successful day, more tomorrow as I work on the create items flow!
