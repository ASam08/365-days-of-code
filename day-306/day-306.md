As promised, today I filled out the updateItem function. Because it shares some code with the createItem function, I actually took the opportunity to split this out into it's own function that both create and update can call, namely the resolveCategoryId function. This basically takes the category ID given, handles if it's a new category, and then also does a sanity check to make sure that the categoryID chosen is actually available to the user (either one of their own or one of the common ones).
