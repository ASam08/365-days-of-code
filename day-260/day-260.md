#  Bits And Pieces
Welcome to **day 260** of 365 days of code - coding every day for a year, little and often

Today definitely was a bits and pieces day. I started off by tidying up the nav bar for the home page. It wasn't quite going all the way across, and I realised that I had missed something in my tailwind classes. I had used "container" for the first time. As a concept, it's something that I can really see the value in using, but of course I just wrote "container", not "@container", so it was just doing, well, nothing.

I also fixed up an issue with the login page. Not really an issue for just the login page, but it was showing an error in the logs anytime I used autofill for the email address. It turns out it was trying to use shadcn's built in type "d" to toggle dark mode. A few extra if statements, to ignore autotyped content, fixed that up.

Lastly, a few tidy ups in the auth.ts file, some inconsistencies with how I had written things, using multiple env variables when one will do, and just a good check through.

All is working, so I think tomorrow will actually be starting to build out the functionality of the app (woohoo!)
