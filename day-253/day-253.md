#  More Dizzle Config
Welcome to **day 253** of 365 days of code - coding every day for a year, little and often

Another pretty straightforward day today, adding more drizzle config. That included setting up placeholder, empty schema and relations files, adding the migrate function that I had from Tempus, and the instrumentation file from Tempus.

The instrumentation one is an important one, it's where I apply all of the Drizzle migrations each time the app boots, checking for any new migrations and applying them. It also checks for missing ENV variables and sets defaults for some, so an important check as I develop the app.

As I work through this, it actually feels like I'm getting towards having a template for any fresh NextJs app with my preferred stack (Postgres, Drizzle, BetterAuth and Resend, with Garage for S3 storage). Once I get to the point that all the placeholder work is done, I might actually take a copy of the repo and create a "My NextJS Boilerplate" repo to help speed this whole piece up next time (I already have ideas...).

Anyway, tomorrow is going to be BetterAuth, more then!
